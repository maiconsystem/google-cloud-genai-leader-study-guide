## How to read the main guide

It is organised by exam domain, in weight order rather than course order:

| Section | Content |
|---|---|
| 1 | **Exam technique** — the elimination method and the six distractor patterns. Do not skip this to get to the content |
| 2 | **Domain 1** — Fundamentals (~30%) |
| 3 | **Domain 2** — Google Cloud's gen AI offerings (~35%) ← **the big one** |
| 4 | **Domain 3** — Techniques to improve model output (~20%) |
| 5 | **Domain 4** — Business strategies (~15%) |
| 6 | **The product cheat sheet** — need → product, on one page |
| 7 | Worked practice questions by domain |
| 8 | Final-week checklist |

**If you only have time for one section, make it Section 3.** If you have time for two, add Section 6.

## A note on product names

The main guide was built from course transcripts recorded before Google's 2026 rebrand, so it uses **Vertex AI** and the older names in places. The [product table](03-product-table.md) is written in the **current** vocabulary, and [docs/04-product-naming-2026.md](../docs/04-product-naming-2026.md) maps between them.

**Where the two disagree, the product table is right — and the [official exam guide](https://services.google.com/fh/files/misc/generative_ai_leader_exam_guide_english.pdf) beats both.**
